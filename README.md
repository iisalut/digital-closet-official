# digital-closet-official
Welcome to my close app ! this is app is made using python and Tkinter.
This app helps you organize your closet digitally
features include :
1. Closet Organization – Upload and tag your clothes by type, color, and season.

2. Outfit Planner – Drag and drop clothing items to assemble outfits visually.

3. Snapshot Functionality – Take snapshots of your planned outfits (saved as PNGs) and store them in a JSON file.

4. User Profiles – Multiple users can save their own closet and outfit data.

5. Customizable Experience – Sort, filter, and explore your closet based on your preferences.

6. Cross-Platform Support – Runs in Python or as a standalone executable(some bugs are present in the executable file.)
  
# Getting Started( Python Version) 
1. Clone the repository or download the project folder.
2. Create a virtual environment (optional but recommended):
python -m venv venv
3. Activate the environment:
macOS/Linux
source venv/bin/activate
Windows
venv\Scripts\activate
4. Install dependencies:
pip install -r requirements.txt
5. Run the app:
python closet_app.py

# Running the Executable
1. Locate the executable:

Windows: dist/closet_app.exe

macOS: dist/closet_app.app
2. Double-click to launch.

⚠️ Some features may behave differently than in the Python version eg: when saving an outfit)

# Troubleshooting
1. Make sure Python 3.12+ is installed.
2. Activate the virtual environment before running the Python version.
3. Ensure all dependencies are installed via requirements.txt.
4. On macOS, if the .app fails, use the Python version.
