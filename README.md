# digital-closet-official
Welcome to my close app ! this app is made using python and Tkinter.
This app helps you organize your closet digitally
features include :
1. Closet Organization – Upload and tag your clothes by type, color, and season.

2. Outfit Planner – Drag and drop clothing items to assemble outfits visually.

3. Snapshot Functionality – Take snapshots of your planned outfits (saved as PNGs) and store them in a JSON file.

4. User Profiles – Multiple users can save their own closet and outfit data.

5. Customizable Experience – Sort, filter, and explore your closet based on your preferences.
6. Fun Challenges - Challenges like random color and aesthetic generators were added to make the outfit styling experience fun

7. Cross-Platform Support – Runs in Python or as a standalone executable (some bugs are present in the executable file.)

# Why I made this project
I often found it frustrating to pick an outfit for school, and I would just wear the same few outfits.
I wanted to improve my organization skills, so I thought just why not make an app that allows me to visualize and save my outfits?
Also this whole app was inspired by Cher from Clueless when she uses her computer to pick an outfit for school :3
I also wanted to further improve my python skills as an intermediate coder :D

# What I struggled with and what I learned
This is my first ever big Python project, and I learned a lot. When I started, I had no clue about Tkinter or any kind of GUIs, and it was also my first time using GitHub. I had to do a lot of research, especially on how to convert images to transparent backgrounds, which was tricky.
I also ran into challenges with the complex iterations I needed for some of my definitions and functions. Figuring out how to structure my code so everything worked together, while managing all the different features like drag-and-drop and outfit snapshots, was really tough! But I learned so much about debugging and organizing a project from start to finish.
However, with the help of youtube tutorials and AI for debugging, I persevered!

# Troubleshooting (The python version is recommended to get the best experience out of my app )
1. Make sure Python 3.12+ is installed.
2. Activate the virtual environment before running the Python version.
3. Ensure all dependencies(like the packages) are installed via requirements.txt.
4. On macOS, if the .app fails, use the Python version.
